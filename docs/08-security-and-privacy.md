# Security and Privacy

*Public, defensible security and privacy statements for a product with real users.*

ClearScan is operated as a product with real users. Public documentation is limited to general, defensible statements.

- GDPR compliance
- EU hosting (database in the Frankfurt region)
- Encryption in transit
- Row-level access control exists
- Payments were handled by Stripe; no card data is stored. Charging is disabled by a feature flag and the payment code is retained.

This repository must not contain customer information, uploaded résumés, production credentials, private source code, or unredacted logs.
