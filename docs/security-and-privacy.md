# Security and Privacy

ClearScan is operated as a live commercial product. Public documentation is limited to general, defensible statements.

- GDPR compliance
- EU hosting (database in the Frankfurt region)
- Encryption in transit
- Row-level access control exists
- Payments handled by Stripe; no card data stored

This repository must not contain customer information, uploaded résumés, production credentials, private source code, or unredacted logs.
