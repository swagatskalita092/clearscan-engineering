# Security policy

This repository contains documentation only. It does not run a service.

## Security concerns about ClearScan

If you find a problem in ClearScan itself at https://clearscan.fyi, please
report it privately using the contact details on that website. Do not open a
public issue and do not post details publicly until it has been fixed.

Please include enough detail to reproduce the problem. Do not access, change or
keep other people's data while investigating.

This is maintained by one person. Responses will be as quick as that allows.

## Sensitive information in this repository

If you notice customer data, a credential or anything else that should not be
public in these files, tell the maintainer privately through the same contact
details.
